# Security Policy

## Supported Versions

Security fixes are applied to the latest state of the `main` branch.

## Reporting a Vulnerability

If you discover a security issue, report it privately by opening a GitHub security advisory or contacting the repository owner directly through GitHub.

Please include:

- A clear description of the issue
- Reproduction steps
- Affected files or components
- Potential impact

## Response Expectations

- Initial triage target: within 72 hours
- Confirmed issues are prioritized by exploitability and impact
- Fixes are released as soon as validation is complete

## Scope Notes

This project processes user-provided documents. Do not upload sensitive or regulated data unless you have explicit authorization and proper safeguards in place.

## Hardening Recommendations

- Run the app in an isolated environment
- Keep dependencies up to date
- Restrict local file-system permissions for runtime directories
- Review third-party model and dependency licenses before production use
